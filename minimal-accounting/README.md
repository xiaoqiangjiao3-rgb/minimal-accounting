# 极简记账系统

基于第一性原理设计的记账工具：**一句话记账 + 自动分类 + 财务建议**

## 核心特性

### 1. 极简输入
- 输入：`午饭麦当劳 42` → 自动识别金额、分类
- 支持语音输入（Chrome 浏览器）
- 实时预览：输入时立即显示分类和金额

### 2. 智能分类
内置 9 大分类，基于关键词自动匹配：
- 🍚 餐饮：饭、餐、吃、麦当劳、外卖...
- 🚗 交通：地铁、公交、打车、加油...
- 🛒 购物：买、淘宝、京东、衣服...
- 🎮 娱乐：电影、游戏、旅游...
- 🏠 居住：房租、水电、物业...
- 💊 医疗：药、医院、体检...
- 📚 教育：书、课程、培训...
- 💰 工资：薪水、奖金、报销...
- 📦 其他

### 3. 财务规划师
点击"💡 财务建议"按钮，内置 AI 规划师会分析：
- 本月收支概览
- 储蓄率评估（健康标准：≥20%）
- 支出结构分析（单一类别不超过 40%）
- 超支预警
- 具体行动建议

### 4. 数据本地存储
- 所有数据保存在浏览器 LocalStorage
- 无需服务器，打开即用
- 支持导出 JSON 备份

## 使用方法

### 基础记账
1. 打开 `index.html`
2. 输入：`午饭 42` → 点击"记"或按回车
3. 自动分类为"餐饮"，记录支出 -¥42

### 快速分类
点击分类按钮（🍚餐饮、🚗交通...），输入框自动填充类别名称，接着输入具体项目和金额即可

### 语音输入
点击 🎤 按钮，说出消费内容（如"午饭四十二块"），自动转文字并识别金额

### 查看财务建议
点击"💡 财务建议"，查看本月财务分析和改进建议

### 删除记录
点击记录右侧的"×"按钮

## 技术实现

### 文件结构
```
minimal-accounting/
├── index.html      # 主界面
├── app.js          # 核心逻辑（分类、建议、存储）
├── style.css       # 极简样式
└── README.md       # 说明文档
```

### 核心技术
- **前端框架**：原生 JavaScript（无依赖）
- **数据存储**：LocalStorage
- **语音识别**：Web Speech API（Chrome）
- **分类算法**：关键词匹配 + 规则引擎
- **财务建议**：基于规则的专家系统

### 分类逻辑
```javascript
// 输入："午饭麦当劳 42"
// 1. 提取金额：42
// 2. 提取描述："午饭麦当劳"
// 3. 关键词匹配："午饭" → 餐饮
// 4. 生成记录：{desc: "午饭麦当劳", amount: -42, category: "餐饮"}
```

### 财务建议规则
- 储蓄率 < 20%：警告，建议优先储蓄
- 单一类别 > 40%：警告，建议优化结构
- 本月超支：紧急建议，暂停非必要消费
- 储蓄率 ≥ 30%：表扬，继续保持

## 第一性原理思考

### 为什么记账？
- **目标**：财务自由 → 需要知道钱去哪了
- **手段**：记录每一笔收支
- **痛点**：传统记账太复杂（选分类、填表单、多个字段）

### 极简设计原则
1. **一句话完成**：`描述 + 金额` → 自动分类
2. **零学习成本**：不需要学怎么用，打开就懂
3. **即时反馈**：输入时实时预览，确认后一键记录
4. **专业建议**：不只是记录，还要给出改进方向

### 与传统记账 App 对比
| 功能 | 传统 App | 极简记账 |
|------|----------|----------|
| 记账步骤 | 3-5 步（选分类、填金额、选账户...） | 1 步（输入一句话） |
| 学习成本 | 高（需要看教程） | 零（打开就用） |
| 分类方式 | 手动选择 | 自动识别 |
| 财务建议 | 无或付费 | 内置免费专家系统 |
| 数据存储 | 云端（隐私风险） | 本地（完全私密） |
